## Featured projects

### 📄 Sheet to Art

**Spreadsheet → publication-grade PDF, 100% client-side.**

Parses `.xlsx`/`.csv`, infers sections and column geometry, then typesets a PDF with Typst WASM inside Web Workers. Deterministic layout engine, five print themes, and no file ever leaves the browser.

`React` `TypeScript` `Vite` `Typst WASM` `Web Workers` · **170 tests** · [Source](https://github.com/YJHacker/Sheet-to-Art)

### ⏱ WLH-App · [Live demo](https://yjhacker.github.io/WLH-App/)

**Work-hours tracker with live analytics.**

Firebase authentication, per-user Firestore data, overlap warnings, and daily / weekly / monthly charts.

`React` `Firebase` `Firestore`

### 🔐 Image Steganography

**AES-GCM-encrypted messages hidden inside PNGs.**

Password-derived keys (PBKDF2), authenticated encryption, then LSB embedding. A wrong password or a modified image fails cleanly instead of returning garbage.

`Python` `Cryptography` `Pillow` · [Source](https://github.com/YJHacker/image-steganography)

### 🗓 Focus Tasks · [Live demo](https://yjhacker.github.io/Focus_Tasks/)

**A single-file habit tracker that stays in the browser.**

Routine timetable with alarms, hydration and exercise counters, weekly streaks, and analytics. All data lives in `localStorage`.

`JavaScript` `Tailwind CSS` `localStorage`
